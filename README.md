# Sea Familia

Marketing site and booking funnels for a boat-charter/liveaboard operator in eastern
Indonesia. Next.js (App Router) + Tailwind v4 + shadcn/ui.

```bash
npm install
npm run dev
```

Full documentation — route map, data contract, the three funnels' state patterns, open
production items — lives in **[docs/HANDOFF.md](docs/HANDOFF.md)**.

This is a Next.js port of a static HTML/Alpine.js site. The original is preserved in
[`legacy/`](../legacy) for reference, and tagged `v1.0-static-handoff` in git history.
